## 3. 主要结论

### 3.1 PM 未达标

- 目标 PM_min = 65°，全轮最佳 61.72°，**差约 3.3°**。
- 后期在 59.5°～60.6° 之间波动，未再超过 iter10。

### 3.2 有效与无效操作

- **对 PM 有利**  
  - XM5/XM6 gm_id 适度下调（如 11.5→9）：iter1→2，PM +1.32°。  
  - XM7/XM8 gm_id 从 8 回到 5：iter8→9，PM +4.19°。  
  - XM1/XM2 gm_id 17.5→15：iter10，PM 达 61.72°（全轮最高）。  
  - XM3/XM4 L 1.2→1.125：iter15，PM 59.66°→60.57°（+0.91°）。

- **对 PM 不利**  
  - XM7/XM8 gm_id 5→8：iter8，PM 55.47°，Gain 53.72 dB，双指标明显变差。  
  - XM5/XM6 gm_id 大幅到 5 且 L 到 1.5：iter3，Gain 跌破 60 dB。  
  - XM5/XM6 gm_id 回升到 7 且 XM3/XM4 L↑：iter4，PM 掉到 56.90°。  
  - XM5/XM6 gm_id 5→9：iter12，PM 54.01°，为全轮最差。

### 3.3 XM7/XM8 行为

- 除 iter8 外，XM7/XM8 均为 **L=1.8, gm_id=5.0**（约束边界）。
- iter8 尝试 **gm_id=8.0**：PM/Gain 明显恶化，iter9 回到 5.0 后恢复。
- 说明：在当前偏置与约束下，**XM7/XM8 保持在 gm_id=5、L=1.8 对 PM 更有利**；提高 gm_id 会恶化 PM 和 Gain。

### 3.4 Gain 与 SR

- Gain 在 iter3、iter6 及之后多轮略低于 60 dB（gap.Gain 约 -0.25～-0.49）。
- iter10 调低 XM1/XM2 gm_id 后，PM 最佳但 Gain=58.83 dB（gap -1.17），SR 从 363 降到 226.5，说明**输入对 gm_id 下调会损 Gain 和 SR**。

## 4. 瓶颈归纳

1. **PM 瓶颈**  
   - XM7/XM8 已卡在 gm_id=5、L=1.8，无法再靠“降 gm_id、增 L”要 PM。  
   - 仅靠上臂 XM5/XM6 和负载/输入对微调，本 run 最高只到 61.72°，距 65° 约 3.3°。

2. **Gain 临界**  
   - 为冲 PM 多次压低 XM5/XM6 gm_id，Gain 多轮在 59.5～60 dB 附近，余量很小。

3. **探索与回退**  
   - iter8 对 XM7/XM8 提高 gm_id 导致 PM/Gain 双崩，说明当前偏置/约束下不宜提高下臂 gm_id；iter12 提高 XM5/XM6 gm_id 同样导致 PM 大跌。
