# 查表策略说明（原表 vs 多表）

## 1. 差异简述

| 来源 | 偏置电流 | 器件模型 | 电流比例（名义） |
|------|----------|----------|------------------|
| **论文网表** | 3µA (CURRENT_0_BIAS=3u) | pfet_01v8 / nfet_01v8 | 以 3µA 为参考 |
| **当前黄金** | 5µA | pfet_01v8_**lvt** / nfet_01v8 | 以 5µA 为参考，第三级 10×→50µA |

- 我们**固定各支路电流**为论文比例：bias=5µA, stage1_tail=20µA, stage1_main=10µA, stage2=5µA, stage3=50µA。
- 黄金仿真**实测** Id 与上述不完全一致（如 xm5/xm6 约 2.48µA、xm8/xm9 约 9.09µA），因电路拓扑与尺寸决定实际分配。

## 2. 建议做法

- **优先：多扫几张「固定 Ids」表，按电流选表查**
  - 生成：`fixed_ids/gmid_nmos_5uA.csv`、`gmid_nmos_50uA.csv`、`gmid_pmos_lvt_5uA.csv` 等（必要时加 10µA、20µA）。
  - 查表时按**当前支路电流**选表（如 xm23 用 50µA 表、bias 用 5µA 表），这样 W = Ids/idW 与设计电流一致，更易贴近黄金 W。
- **备选：仅用原表**
  - 不生成新表，继续用 `gmid_nmos.csv` / `gmid_pmos_lvt.csv`；首轮用黄金覆盖 + 未改管保留上轮 W，多数管约 0.7~1× 黄金，可跑通但个别管偏差大（如 xm5/xm6、xm17/xm18）。

## 3. 结论

- **与论文完全一致**：论文 3µA、不同工艺/模型，无法直接复刻。
- **与当前黄金一致**：固定 5µA 比例 + 多表（5/10/20/50µA）按电流选表，能更好复现黄金 W；仅用原表也可工作，依赖黄金初值与 W 保留。

脚本 `verify_golden_vs_table.py` 用于对比「黄金 L/gm_id/理论电流 + 原表」算出的 W 与黄金 W。
